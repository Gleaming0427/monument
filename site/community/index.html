Monuments other people built with the skill, each with the prompt that made it.

Every monument here was sent to Gleaming0427/monument as a file, checked, rebuilt from it and photographed at one size, so only the building is left.

Add yours 01

Build a monument with the skill as usual. Then, in the same session, ask your agent:

publish this monument to the community gallery

It asks for a title, a short id and your GitHub name, shows what it will send, and opens the pull request for you. Without a terminal, put monuments/<id>.json in a Gist and fill in the Submit a monument form.

Say which model built it, with --model or the form’s Model field. The rules, and what the checks do with your file, are in the repository’s CONTRIBUTING.md.
